# decisions

Record of important, long-term architectural and technical decisions along with their rationale.

## What belongs here

* architectural and technical decisions of lasting significance to the project;
* the context and reasoning behind a chosen solution.

## Rules

* When a decision becomes outdated or superseded, the historical context is preserved and the entry is clearly marked as superseded.
* Historical reasoning must not be silently rewritten in a way that hides why an earlier decision was made.
* This file (`README.md`) is the only file from this directory tracked in GitHub — see `.gitignore` in the root directory.
