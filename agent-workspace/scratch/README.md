# scratch

The agent's temporary working space, free to use however needed while working on a task.

## What belongs here

* temporary material produced during investigation/analysis;
* working files that have no value beyond the current task.

## Rules

* Contents of this directory may be freely created, modified, reorganized, or deleted.
* The agent periodically cleans up artifacts that are no longer useful.
* Important discoveries must not remain only in `scratch` — before removing temporary files, promote valuable information to the appropriate persistent directory (`memory`, `decisions`, `references`, etc.).
* This file (`README.md`) is the only file from this directory tracked in GitHub — see `.gitignore` in the root directory.
