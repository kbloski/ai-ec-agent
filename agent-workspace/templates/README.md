# templates

Reusable document structures that keep other working directories consistent.

## What belongs here

* templates for recurring documents, e.g.:

```text
templates/
├── PLAN.md
├── DECISION.md
└── MEMORY.md
```

## Rules

* Templates are created only when they improve consistency or efficiency for recurring work — not for one-off documents.
* This file (`README.md`) is the only file from this directory tracked in GitHub — see `.gitignore` in the root directory.
