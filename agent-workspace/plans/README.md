# plans

Living working documents describing the implementation strategy for current tasks.

## What belongs here

* active implementation plans for ongoing tasks;
* progress tracking (completed steps, newly discovered steps);
* blockers and important discoveries made while working;
* unresolved questions.

## Rules

* A plan should reflect the current state of the work, not just the state it was in when planning started.
* The agent updates the existing plan as work progresses instead of creating a new one for every minor change in approach.
* A new plan is created for a new task, not for another iteration of the same task.
* This file (`README.md`) is the only file from this directory tracked in GitHub — see `.gitignore` in the root directory.
