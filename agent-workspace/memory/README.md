# memory

The agent's living knowledge base — important, non-obvious information discovered while working on the project.

## What belongs here

* non-obvious system behavior discovered during development;
* durable knowledge useful across future sessions;
* topical subdirectories when useful, e.g.:

```text
memory/
├── architecture/
├── integrations/
└── debugging/
```

## Rules

* The agent may freely create, update, merge, and reorganize memory files.
* The goal is not to accumulate as much information as possible, but to maintain high-quality, useful context.
* Clearly outdated information is corrected or removed.
* This file (`README.md`) is the only file from this directory tracked in GitHub — see `.gitignore` in the root directory.
